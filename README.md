## 🚀 About Me

I'm a backend developer who loves building things that scale, and lately, things that think. 🧠

- ⚙️ I enjoy designing **APIs, auth flows and event-driven systems** in **Node.js**
- 🤖 I build **LLM agents, RAG pipelines and MCP servers** in **Python**
- ☁️ Happiest when wiring up **serverless workflows** on **AWS** and **GCP**
- 🔐 Weirdly fond of **SSO, RBAC and multi-tenant** architecture puzzles
- 💬 Ask me about **LangGraph, Model Context Protocol, or knowledge graphs + vector search**
